# DomeLink Frontend

Premium React application for browsing architects, booking consultations, realtime messaging, and admin analytics.

## Tech

- Vite
- React 18 + TypeScript
- Tailwind + shadcn/ui
- Framer Motion
- React Query
- React Three Fiber / Drei

## Setup

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Default URL: `http://localhost:8080`

## Required Env

- `VITE_API_BASE_URL` (validated at startup)

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run test
```

## Key UX Areas

- Explore + recommendations
- Saved architects
- Architect profile with consultation flow
- Realtime chat modal
- Architect team workspace
- Admin analytics dashboard
