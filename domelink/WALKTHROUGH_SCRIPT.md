# DomeLink Demo Video Script

**Target Audience:** Technical Recruiters, Investors, Technical Founders.
**Vibe:** Premium, cinematic, focused, calm.
**Recording Setup:** Chrome in full screen, clean desktop, dark mode OS.
**Total Duration:** ~2.5 Minutes.

## Sc. 1: Landing Page (The Hook)
* **Visual:** The 3D interactive hero scene rendering the glass dome. 
* **Action:** Cursor slowly moves to tilt the 3D element.
* **Narration:** "Welcome to DomeLink. Most homeowners navigate architecture through unverified portfolios and fragmented communication. DomeLink replaces uncertainty with an intelligent, cinematic ecosystem."
* **Duration:** 15 seconds

## Sc. 2: Recruiter Quick Start (The Magic)
* **Visual:** Click "Recruiter Quick Tour" CTA on the hero page.
* **Narration:** "We've built a recruiter-ready sandbox. With one click, we log in as a premium verified studio to see real momentum."
* **Action:** Fast-forward through the login directly into the *Architect Dashboard*.
* **Duration:** 15 seconds

## Sc. 3: Ecosystem Intelligence (The Architecture)
* **Visual:** The Architect Dashboard charts animating in (Recharts). Hovering over data points.
* **Narration:** "Under the hood, DomeLink is entirely production-ready. The dashboard pulls realtime metrics from our PostgreSQL Prisma store, while high-stakes actions are logged into our immutable Enterprise Audit service."
* **Duration:** 20 seconds

## Sc. 4: Avora Intelligence (The Differentiator)
* **Visual:** Switch tabs to the Homeowner view `Avora Estimate`. Enter a plot size (2400 sqft), select "Tropical Modern". Click Generate.
* **Action:** Let the loader spin (Groq LLM invocation). The feasibility report slides in.
* **Narration:** "Before a client even meets a studio, our proprietary AI, Avora, calculates a highly accurate regional cost feasibility report. It uses a cache-first architecture, meaning identical constraints hit a 10ms memory layer, avoiding token bloat and LLM rate-limits entirely."
* **Duration:** 35 seconds

## Sc. 5: Realtime Workspace (The Edge)
* **Visual:** Open a Consultation chat modal. Type a message.
* **Narration:** "When constraints are met, the consultation bridges the gap. The messaging ecosystem is fully realtime, powered by Socket.io, allowing fluid, continuous dialogues between studios and clients."
* **Duration:** 25 seconds

## Sc. 6: The Tech Stack Matrix (The Close)
* **Visual:** Open the Developer Network or the Chrome DevTools network tab showing manual chunk splitting (loading only what's needed).
* **Narration:** "DomeLink is built on a heavily optimized Vite/React pipeline, with strict Zod validation on the Express layer. From suspicious-pattern drop-middleware to React-ErrorBoundary crash telemetry routed natively into Sentry, DomeLink is built for the enterprise, from day one."
* **Duration:** 40 seconds

*(End on the homepage hero, panning the background)*
