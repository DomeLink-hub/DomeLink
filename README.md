## 🛠️ Local Development Setup

### 1️⃣ Clone the repo

```bash
git clone https://github.com/Krish00711/DomeLink.git
cd DomeLink
```

---

### 2️⃣ Backend setup

```bash
cd domelink/backend
npm install
```

Create `.env`:

```env
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret
OPENAI_API_KEY=your_key
PORT=5000
```

Run:

```bash
npm run dev
```

---

### 3️⃣ Frontend setup

```bash
cd ../frontend
npm install
npm run dev
```
